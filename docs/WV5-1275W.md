# LG WV5-1275W

ThinQ model `F_V7_Y___W.A__QEUK`, tested on firmware 2.9.61. Provides
21 monitoring entities and five command buttons in Home Assistant.

## Using the controls

Open the **LG Washer** device in Home Assistant. Select the programme and
settings at the washer and enable Remote Start there.

- **Start** starts the programme currently reported by the washer, with its
  existing temperature, spin, rinse and options. It does not set a finish delay.
- **Pause** pauses the current cycle. **Resume** continues it with its reported
  settings, including any remaining delay reservation.
- **Wake up** wakes a washer in standby. Wait until **Standby** is off before
  pressing Start. Wake up does not start a wash, power on a fully switched-off
  appliance, or enable Remote Start.
- **Power off** switches the washer off and cancels an active delay reservation.

**Idle** and **Standby** are different: an idle washer can be awake or asleep.
Remote Start can remain enabled while asleep. Start and Resume need a status
report from the current connection; reconnecting does not reuse old settings.
Only appliance reports update the sensors. Commands are not queued or retried,
and the washer enforces its own door and operating-state restrictions.

Programme selection, option editing, delay scheduling and programme downloads
are not exposed. The sensors still recognize all 24 downloaded programmes,
and Start can use a downloaded programme already selected on the washer.

## Validation and limitations

Tests replay real packets, including 496 comparisons with independent LG state
notifications. Current-record offsets differ from sibling washer models; the
second record is current and the first is previous state. Start uses LG's `03`
control flags; the captured HA Start additionally echoed doorLock (`43`). The
Start test accounts for that difference. Pause, Resume, Wake up and Power off
match captured commands byte-for-byte.

Native testing verified Pause/Resume during Tub Clean, Wake up followed by
Start, and Power off cancelling a confirmed delay reservation. Tub Clean and
Quick 30 completed; the cleaning counter reset and subsequently incremented.
Some captures include programme-selection and download commands from the fuller
test setup; those controls are not part of this handler. Captures retain packet
bytes and relative timings without account IDs or network addresses.

No initial status query is sent: readings require fresh appliance reports.
The wake response `20 2B 01 00` retransmitted ten times during testing; its LG
delivery acknowledgement is not yet captured, so the handler does not guess it.
Wake and subsequent Start succeeded. Smart Diagnosis results, energy/water
measurements and remote power-on from fully off are not exposed.
